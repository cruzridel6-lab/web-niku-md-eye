Conectar con WhatsApp

Cómo conectar tu número

  1. Escribe tu número con código de país, sin «+», espacios ni paréntesis.
  2. Pulsa «Solicitar código de vinculación».
  3. Copia el código de ocho dígitos.
  4. Abre WhatsApp → Ajustes → Dispositivos vinculados.
  5. Introduce el código cuando WhatsApp lo solicite.
